# 1. 一元线性回归残差性质证明

一元线性回归模型：\(y_i = \beta_0+\beta_1 x_i+\varepsilon_i\) 拟合方程：\(\hat y_i = \hat\beta_0+\hat\beta_1 x_i\) 残差定义：\(e_i = y_i-\hat y_i\)

最小二乘目标：\(\min \sum_{i=1}^n e_i^2=\min\sum_{i=1}^n(y_i-\hat\beta_0-\hat\beta_1 x_i)^2\)

对\(\hat\beta_0\)求偏导并令其等于 0：

\(\frac{\partial}{\partial\hat\beta_0}\sum e_i^2 = -2\sum_{i=1}^n(y_i-\hat\beta_0-\hat\beta_1 x_i)=0\) \(\sum_{i=1}^n(y_i-\hat\beta_0-\hat\beta_1 x_i)=0 \implies \boldsymbol{\sum_{i=1}^n e_i = 0}\)

对\(\hat\beta_1\)求偏导并令其等于 0：

\(\frac{\partial}{\partial\hat\beta_1}\sum e_i^2 = -2\sum_{i=1}^n x_i(y_i-\hat\beta_0-\hat\beta_1 x_i)=0\) \(\boldsymbol{\sum_{i=1}^n x_i e_i = 0}\)

# 2. 多元回归添加无关随机特征，\(R^2\)上升，\(\boldsymbol{R^2_{adj}}\)下降的解释

\(R^2\)定义：

\(R^2 = 1-\frac{RSS}{TSS}\)

\(TSS=\sum(y_i-\bar y)^2\)（总平方和，固定不变），RSS为残差平方和。

调整\(R^2_{adj}\)定义：

\(R^2_{adj}=1-\frac{RSS/(n-k-1)}{TSS/(n-1)}\)

- n：样本量
- k：自变量个数

### 原理

1. **\(R^2\)**：每新增一个自变量，无论这个变量和y有没有真实关系，最小二乘都会利用这个新参数去 “拟合噪声”，**RSS 一定不会变大，只会减小或不变**。TSS不变，因此\(R^2\)上升或保持不变。\(R^2\)**不考虑自由度惩罚**。
2. **\(R^2_{adj}\)**：公式带有自由度惩罚项。新增无关变量后：
   - RSS小幅下降；
   - 参数个数k增加，分母\(n-k-1\)变小，\(\frac{RSS}{n-k-1}\)会变大；
   - 惩罚效应超过 RSS 下降带来的收益，最终\(\boldsymbol{R^2_{adj}}\)下降。
