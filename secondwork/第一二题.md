# 第 1 题 一元线性回归残差性质证明
最小二乘法的核心目标是最小化残差平方和：
$\min_{\hat{\beta}_0,\hat{\beta}_1} \sum_{i=1}^n e_i^2 = \sum_{i=1}^n \left(y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i\right)^2$

分别对截距项 $\hat{\beta}_0$ 和斜率项 $\hat{\beta}_1$ 求偏导，并令偏导数等于 0，得到极值条件：

$$
\begin{cases}
\displaystyle \frac{\partial \sum_{i=1}^n e_i^2}{\partial \hat{\beta}_0} = -2\sum_{i=1}^n \left(y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i\right) = 0 \\[10pt]
\displaystyle \frac{\partial \sum_{i=1}^n e_i^2}{\partial \hat{\beta}_1} = -2\sum_{i=1}^n x_i\left(y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i\right) = 0
\end{cases}
$$

约去系数 $-2$ 后，得到最小二乘估计的正规方程组：

$$
\begin{cases}
\displaystyle \sum_{i=1}^n \left(y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i\right) = 0 \\[8pt]
\displaystyle \sum_{i=1}^n x_i\left(y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i\right) = 0
\end{cases}
$$

将残差定义 $e_i = y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i$ 代入第一个正规方程，可得：
$\sum_{i=1}^n e_i = \sum_{i=1}^n \left(y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i\right) = 0$

即：
$\boldsymbol{\sum_{i=1}^n e_i = 0}$

将残差定义 $e_i = y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i$ 代入第二个正规方程，可得：
$\sum_{i=1}^n x_i e_i = \sum_{i=1}^n x_i\left(y_i - \hat{\beta}_0 - \hat{\beta}_1 x_i\right) = 0$

即：
$\boldsymbol{\sum_{i=1}^n x_i e_i = 0}$

# 第 2 题 新增无关特征对$R^2$与$R^2_{adj}$的影响
### 公式
$R^2 = 1-\frac{RSS}{TSS},\quad R^2_{adj}=1-\frac{RSS/(n-k-1)}{TSS/(n-1)}$

### 1. $R^2$上升或不变
新增无关变量时，最小二乘拟合使**RSS 只减不增**，TSS 固定不变，因此$R^2$上升或保持不变。 $R^2$无自由度惩罚，新增变量总会提升或维持其数值。

### 2. $R^2_{adj}$下降
新增变量使k增大，残差自由度$n-k-1$减小。 无关变量对 RSS 降低作用微弱，自由度下降的惩罚效应更强，导致$\frac{RSS}{n-k-1}$上升，最终$R^2_{adj}$下降。
